# Data directory

Do not commit datasets, citizen-submitted photos, or private information to this repository.

Before using a dataset:
1. Record its source URL, license, version/date, and intended use.
2. Confirm the class labels and annotation format.
3. Document how train/validation/test splits were created.
4. Keep large files in an approved storage location and provide setup/download instructions here.

Use fabricated or approved public examples for demos. Blur faces and license plates in locally collected photos used in documentation or demonstrations.
