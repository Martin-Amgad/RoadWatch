# Citizen mobile app

**Planned stack:** Flutter / Dart.

## Responsibilities
- Capture a road-damage photo or select one from the gallery.
- Request camera and location permissions with clear fallback states.
- Display the backend's damage category, confidence, and **preliminary** severity.
- Allow an optional description and submit the report with location.
- Show success/failure feedback and the returned report ID.
- Show the citizen's submitted reports if that feature is included in the agreed MVP.

## Planned screens
1. Home / report damage
2. Capture or choose photo
3. AI result review (including no-detection state)
4. Location and optional description
5. Submission confirmation
6. My reports / report status

No Flutter app has been implemented in this starter scaffold yet.
