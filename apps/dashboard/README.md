# Municipal staff dashboard

**Planned stack:** Web framework to be selected by the team.

## Responsibilities
- List reports with highest preliminary severity first; break ties by newest submission.
- Filter by damage category and report status.
- Show photo, category, severity, GPS coordinates, description, submission date, and status.
- Show geographically grouped reports as **potential duplicates**, while keeping each report individually accessible.
- Allow authorized staff to update status: `Submitted`, `Under Review`, `Resolved`.

## Planned screens
1. Overview / recent reports
2. All reports with search and filters
3. Report details and status controls
4. Potential duplicate groups

An interactive map is optional and should not delay the MVP. No dashboard has been implemented yet.
